How it works
  1. The page holds the owner's public key. Your handle, answer and a timestamp are encrypted in your browser (ECDH P-256 with a fresh one-time key + AES-256-GCM) and shown as HEX.
  2. Nothing is sent anywhere. You paste the code in the comments yourself.
  3. Only the owner's private key can decrypt it. That key and the correct answer sit in this page only encrypted with the owner's passphrase (PBKDF2-SHA256, 600k iterations + AES-GCM).
  4. The owner unlocks, pastes all comments, and sees who answered correctly.
Create your own riddle

Don't reuse this demo's keys. Run tools/make_riddle.py --image your.png --answer "..." --passphrase-file secret.txt --question "..." --out my-riddle.html from the repo. It makes a fresh keypair and puts the answer only inside the encrypted owner bundle. Host the HTML next to the image.
